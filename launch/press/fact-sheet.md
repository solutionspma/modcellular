## Product

### What It Is
Decentralized communication app that works without cell service by routing messages via WiFi, Bluetooth mesh, and satellite fallback.

### How It Works
1. App scans for WiFi, Bluetooth devices, mesh nodes, satellite signals
2. Scores each link by strength, latency, bandwidth
3. Routes message via best available path
4. Splits messages into 250-byte micro-packets
5. Relayers earn MODX tokens for forwarding packets

### Platform
iOS 13+ | Android 8+  
Built with React Native (Expo 51)

### Blockchain
Ethereum, Polygon, Base, Arbitrum, Optimism  
Token: MODX (ERC-20)  
Total Supply: 1 billion tokens  

---

## Key Innovation

**Relay Mining:** Users earn MODX tokens for forwarding packets, similar to Helium but for communication instead of IoT.

This creates a sustainable economic model where network participants are rewarded for contributing infrastructure, enabling organic growth without traditional VC-funded user acquisition.

## Technology Stack

### Core Routing
- Multi-protocol switching (WiFi/Bluetooth/mesh/DTN/satellite)
- Micro-packet engine (250-byte chunks)
- Link scoring algorithm (0-150 points)
- Adaptive bandwidth (10%-100% quality)
- Predictive routing (ML-based)

### Voice
- VOMP (Voice Over Micro-Packets) encoder/decoder
- Voice muxer (multi-link distribution)
- Codec selection (Opus/PCM/GSM)
- Group calls (up to 8 participants)

### Security
- End-to-end encryption (Signal Protocol-inspired)
- Device identity management
- Session handling
- Zero metadata collection

### Offline Support
- DTN (Delay-Tolerant Networking) queue
- 7-day message retention
- Auto-sync when reconnected
- 94.7% delivery rate within 24 hours

### Emergency
- SOS beacon (priority 999)
- Emergency broadcast to all nearby devices
- Thermal guard (prevents device overheating)
- Automatic failover
